# DSW 2026 · Unidad IV — HTML, CSS y JavaScript

Guía de estudio interactiva, desarrollada diapositiva por diapositiva (127 diapositivas, 20 temas).

**Incluye:**
- Índice lateral por tema y número de diapositiva
- Explicación desarrollada, ejemplos de código para copiar y la diapositiva original de cada una
- Cajas de erratas/precisiones (⚠️) y soluciones de los ejercicios #17 a #25 (🧪)
- Preguntas "¿Lo entendiste?" con respuestas ocultas
- Búsqueda que ignora las tildes (atajo `/`), modo claro/oscuro y avance guardado en el navegador
- Demos interactivas: Flexbox, DOM, eventos, Promise, fetch, validación y Event Loop paso a paso

## Estructura

```
index.html      ← la guía completa (HTML + CSS + JS en un solo archivo)
slides/         ← imágenes de las diapositivas originales (001.jpg … 127.jpg)
README.md
```

## Verla en tu computadora

Abrí `index.html` con doble clic. (La demo de `fetch` necesita internet.)

## Publicarla con GitHub Pages

1. Creá un repositorio público (por ejemplo `dsw-unidad4`).
2. Subí `index.html`, `README.md` y la carpeta `slides/`.
3. En el repositorio: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, elegí la rama `main` y la carpeta `/ (root)` → **Save**.
4. En 1–2 minutos queda en `https://TU-USUARIO.github.io/dsw-unidad4/`.

Material basado en las diapositivas de la cátedra Desarrollo de Software 2026 (UTN FRT).
